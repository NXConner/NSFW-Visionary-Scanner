## Common Issues & Solutions

### Issue: Feature taking longer than estimated
**Solution**: Break into smaller tasks, reassess timeline, adjust plan

### Issue: Blocker identified
**Solution**: Document immediately, assign owner, create resolution plan, escalate if needed

### Issue: Team member unavailable
**Solution**: Redistribute tasks, adjust timeline, communicate changes

### Issue: Requirements unclear
**Solution**: Review source documents, clarify with team, update documentation
