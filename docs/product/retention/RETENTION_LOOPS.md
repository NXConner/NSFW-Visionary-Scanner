# Retention Loops — MorphoScan Pro

## Goal

Increase LTV by improving short-term retention (D1/D7) and reducing churn.

## Core retention loops (v1)

### Loop 1 — Plan → Action → Reward

- User chooses a plan (solo/couples)
- Daily action takes < 2 minutes
- Reward: progress visualization + streak (forgiving streak logic)

### Loop 2 — Weekly Review

- Weekly summary highlights progress + next step
- One recommended action for the upcoming week

### Loop 3 — Partner / Couples

- Partner invite with privacy boundaries
- Shared challenges and communication prompts
- Optional scheduling (“date night planner”) without explicit content in store build

## Notifications (rules)

- User-controlled frequency and quiet hours
- No explicit notification text
- Actionable reminders (not spam)

## Metrics

- D1/D7/D30 retention
- Weekly plan completion rate
- Notification opt-in rate
- Cancellation reasons

## Experiments

- Improve onboarding personalization
- Add “week in review” card
- Streak forgiveness + comeback flows
